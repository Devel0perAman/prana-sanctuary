Drop your own media here (or run `npm run media`):

- hero.mp4        — homepage background video (720p H.264, no audio, ≤ 6 MB recommended)
- hero.webm       — optional smaller VP9 copy
- hero-poster.jpg — first frame shown while the video loads
- img/<key>.jpg   — photos; keys are listed in src/data/media-sources.json
- manifest.json   — written by `npm run media`; maps keys to local files
